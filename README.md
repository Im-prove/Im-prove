## About

I’m a Computer Science student building across the stack—from low-level hardware and embedded systems to intelligent software, AI workflows, and practical applications.

My interests are broad but connected: I enjoy understanding how **AI, language systems, robotics, embedded hardware, and software engineering** fit together in real-world products. I learn by building, testing, debugging, and improving systems that solve actual problems rather than only demonstrating concepts.

### Current focus

- 🧠 AI / ML, deep learning, NLP, computer vision, and applied intelligence
- 🔎 Retrieval-Augmented Generation, embeddings, semantic search, and LLM workflows
- 🤖 Robotics, autonomous systems, sensing, navigation, and control
- ⚙️ Arduino, STM32, Raspberry Pi, firmware, and IoT integration
- 💻 Python, backend services, web applications, automation, and developer tooling
