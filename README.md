## About

I am a Computer Science student exploring how software, hardware, and intelligence connect. My work spans **AI and machine learning, NLP, deep learning, RAG, LLM applications, robotics, embedded systems, IoT, and practical software engineering**.

I enjoy building systems that solve real problems, learning by doing, and understanding how the full stack works—from microcontrollers and sensors to language models, APIs, and user-facing applications.

- 🔭 Exploring AI, ML, NLP, RAG, and LLM-based applications
- 🤖 Working across robotics, embedded systems, and hardware integration
- ⚙️ Using Arduino, STM microcontrollers, Raspberry Pi, and IoT systems
- 💻 Building with Python, JavaScript, TypeScript, C, C++, PHP, HTML, CSS, and Shell
- 🌱 Learning through projects, iterations, and hands-on implementation
