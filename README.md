## Profile

I am a Computer Science student exploring how software, intelligent systems, and hardware work together. My projects cover **AI and machine learning, natural language processing, deep learning, RAG, LLM applications, robotics, embedded systems, IoT, and web development**.

I learn through implementation: designing an idea, building a working version, understanding the system behind it, and improving it through iteration.

### Current focus

- **AI / ML:** machine learning, deep learning, NLP, RAG, LLMs, and applied AI
- **Robotics:** autonomous systems, sensing, control, navigation, and experimentation
- **Embedded:** Arduino, STM microcontrollers, Raspberry Pi, firmware, and hardware integration
- **Software:** Python applications, APIs, web systems, automation, and developer tooling
- **Foundations:** algorithms, data structures, systems, networks, databases, and software engineering
